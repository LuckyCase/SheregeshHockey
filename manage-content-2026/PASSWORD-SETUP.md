# Настройка пароля для админ-панели

## Текущий пароль

По умолчанию установлен пустой пароль (просто нажмите "Войти" без ввода).

## Как изменить пароль

1. Откройте консоль браузера (F12 → Console)
2. Выполните команду для генерации SHA-256 хеша от вашего пароля:

```javascript
async function generatePasswordHash(password) {
  const buffer = new TextEncoder().encode(password);
  const hash = await crypto.subtle.digest('SHA-256', buffer);
  const hex = Array.from(new Uint8Array(hash))
    .map(b => b.toString(16).padStart(2, '0'))
    .join('');
  console.log('Ваш хеш:', hex);
  return hex;
}

// Пример: сгенерировать хеш для пароля "mysecretpass123"
generatePasswordHash('mysecretpass123');
```

3. Скопируйте полученный хеш
4. Откройте файл `manage-content-2026/index.html`
5. Найдите строку (примерно строка 751):

```javascript
var PASSWORD_HASH = 'e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855';
```

6. Замените значение на ваш хеш:

```javascript
var PASSWORD_HASH = 'ваш_новый_хеш_здесь';
```

7. Сохраните файл и закоммитьте изменения

## Примеры хешей

(для примера - используйте generatePasswordHash для генерации реального хеша)

## Безопасность

- Пароль **не хранится в открытом виде** в коде
- Используется криптографически стойкая функция SHA-256
- Проверка пароля происходит **только на стороне клиента**
- Сессия хранится в `sessionStorage` (удаляется при закрытии вкладки)
- Комбинация обфусцированного URL (`/manage-content-2026/`) + пароль обеспечивает двухфакторную защиту

## Рекомендации

1. Используйте **сложный пароль** (минимум 12 символов, буквы + цифры + символы)
2. **Не коммитьте** пароль или хеш в публичные сообщения коммитов
3. После смены пароля **очистите историю консоли браузера**
4. Храните пароль в **менеджере паролей** (1Password, Bitwarden и т.д.)
5. Периодически **меняйте пароль** (раз в 3-6 месяцев)

## Восстановление доступа

Если забыли пароль:
1. Откройте `manage-content-2026/index.html`
2. Временно замените `PASSWORD_HASH` на хеш пустой строки (см. выше)
3. Войдите без пароля
4. Создайте новый хеш и обновите `PASSWORD_HASH`
