🎬 Тест: Остановка видео при закрытии модального окна

Проблема: При закрытии модального окна с видео, звук продолжает воспроизводиться в фоне.
✅ Решение: При закрытии модального окна iframe удаляется из DOM, что автоматически останавливает воспроизведение.

Шаги тестирования:

  1. Нажмите кнопку "Открыть модальное окно с видео"
  2. Дождитесь загрузки видео и начните воспроизведение (нажмите Play)
  3. Пока видео играет, закройте модальное окно (кнопка X или Escape)
  4. Проверьте: звук должен остановиться сразу после закрытия

Видео из VK.com

Что происходит при закрытии:
1. Модальное окно начинает анимацию закрытия (opacity)
2. Через 400мс (после завершения анимации) контент очищается
3. Удаление iframe из DOM останавливает воспроизведение

Технические детали:

Код функции closeModal():

function closeNewsModal() {
  var modal = document.getElementById('news-modal');
  var body = document.getElementById('news-modal-body');
  if (!modal) return;

  // Удаляем фокус
  if (document.activeElement && modal.contains(document.activeElement)) {
    document.activeElement.blur();
  }

  // Закрываем модальное окно
  modal.setAttribute('aria-hidden', 'true');
  modal.setAttribute('hidden', '');
  document.body.style.overflow = '';

  // Очищаем контент после завершения анимации (400мс)
  // Это удаляет iframe из DOM и останавливает видео
  setTimeout(function() {
    if (body && modal.getAttribute('aria-hidden') === 'true') {
      body.innerHTML = '';  // 👈 Ключевая строка!
    }
  }, 400);
}
