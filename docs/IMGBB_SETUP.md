# Настройка ImgBB для формы обратной связи

⚠️ **Важно**: Imgur API больше не принимает новые регистрации с 2025 года. Мы используем **ImgBB** — бесплатную альтернативу с теми же возможностями.

## Шаг 1: Регистрация на ImgBB

1. Перейдите на https://imgbb.com/signup
2. Создайте бесплатный аккаунт:
   - Введите email и пароль
   - Или войдите через Google/Facebook
3. Подтвердите email (если требуется)

## Шаг 2: Получите API Key

1. После входа перейдите на https://api.imgbb.com/
2. Нажмите кнопку **"Get API Key"**
3. Скопируйте ваш API Key (строка вида `abc123def456...`)

**Скриншот примера:**
```
Your API Key: abc123def456789xyz (нажмите, чтобы скопировать)
```

## Шаг 3: Добавьте API Key в код

Откройте файл `assets/js/modules/contact-form.js` и замените строку 5:

```javascript
var IMGBB_API_KEY = 'YOUR_IMGBB_API_KEY';
```

на:

```javascript
var IMGBB_API_KEY = 'ваш_api_key_здесь';
```

## Шаг 4: Сохраните и протестируйте

1. Сохраните файл
2. Откройте сайт в браузере
3. Нажмите "Написать нам"
4. Выберите фото и отправьте форму
5. Проверьте, что письмо пришло со ссылками на фото

## Лимиты бесплатного плана ImgBB

✅ **БЕЗ ЛИМИТОВ на API-запросы**  
✅ До **32 MB** на изображение (больше чем у Imgur!)  
✅ Форматы: **JPEG, PNG, GIF, BMP, TIFF, WebP**  
✅ Множественная загрузка  
✅ Прямые ссылки на изображения  

## Проверка загруженных изображений

Все загруженные изображения доступны по прямым ссылкам вида:
`https://i.ibb.co/{hash}/{filename}.jpg`

Вы также можете просмотреть их на странице:
`https://ibb.co/{hash}`

## Безопасность

API Key **можно публично использовать** в клиентском коде — это предназначено для браузерных приложений. Тем не менее:

⚠️ Если вы беспокоитесь о безопасности, можете ограничить использование ключа:
- Настройте CORS на сервере (если используете прокси)
- Или используйте домен-ограничения в настройках ImgBB

## Преимущества ImgBB над Imgur

✅ **Принимает новые регистрации** (Imgur — нет)  
✅ **Без лимитов API** (Imgur — 1250/день)  
✅ **До 32 MB** на файл (Imgur — 20 MB)  
✅ **Быстрая регистрация** (2 минуты)  
✅ **Надёжный сервис** с 2010 года  

## Альтернатива 2: Cloudinary (если нужно больше)

Если ImgBB не подойдёт, можно использовать **Cloudinary**:

1. Зарегистрируйтесь на https://cloudinary.com/
2. Бесплатно: 25 GB хранилища, 25 GB трафика/месяц
3. Получите Cloud Name и Upload Preset
4. Используйте их unsigned upload API

Cloudinary более профессиональный, но ImgBB проще для старта.

## Альтернатива 3: GitHub Issues (совсем бесплатно)

Если не хотите внешние сервисы, можно использовать GitHub Issues:
- Полностью бесплатно
- До 25 MB на файл
- Все сообщения в вашем репозитории
- Требует GitHub Personal Access Token
