# Быстрая справка: Добавление видео в новости

## TL;DR

Чтобы добавить видео из VK.com в новость:

1. Скопируйте прямую ссылку на видео VK (например, `https://vk.com/video-227283438_456239037`)
2. Откройте `assets/js/data/today-data.json`
3. Добавьте поле `videoUrl` в новость:

```json
{
  "id": "news-id",
  "date": "2026-02-16",
  "titleRu": "Заголовок",
  "titleEn": "Title",
  "contentRu": "Текст новости...",
  "contentEn": "News text...",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": ["assets/images/today/news/preview.jpg"],
  "pinned": false
}
```

4. Готово! Видео автоматически встроится в новость.

---

## Важно

- ✅ Используйте **прямую ссылку** на видео: `https://vk.com/video{oid}_{id}`
- ✅ Убедитесь, что видео **доступно без авторизации** (проверьте в режиме инкогнито)
- ✅ Добавьте **превью-изображение** в массив `images` — оно будет использоваться как обложка

---

## Где взять ссылку на видео VK

1. Откройте видео на VK.com
2. Скопируйте URL из адресной строки браузера
3. Формат: `https://vk.com/video-227283438_456239037`
   - `-227283438` — ID владельца (группа/сообщество, начинается с минуса)
   - `456239037` — ID видео

---

## Результат

### В карточке новости:
- Превью с иконкой воспроизведения ▶️ (если есть изображение)
- Или иконка видеокамеры 🎥 (если нет изображения)

### В модальном окне:
- Видео вверху (вместо баннера)
- Остальные изображения внизу (если есть)
