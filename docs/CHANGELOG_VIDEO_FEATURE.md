## Как работает:

### 1. Добавление новости с видео:

В файл `assets/js/data/today-data.json` добавить новость с полем `videoUrl`:

```json
{
  "videoUrl": "https://vk.com/video-227283438_456239037"
}
```

### 2. Автоматическая обработка:

- JavaScript парсит ссылку и извлекает `oid` и `id`
- Генерируется embed-URL: `https://vk.com/video_ext.php?oid=...&id=...`
- Создаётся адаптивный iframe с соотношением сторон 16:9

### 3. Отображение:

- **В карточке:** превью с иконкой play (если есть изображение) или иконка видео
- **В модальном окне:** полноразмерное видео с возможностью воспроизведения

## Технические детали:

### Поддерживаемые платформы:
- ✅ VK.com (видео сообществ и пользователей)
- ❌ YouTube (пока не поддерживается)
- ❌ Rutube (пока не поддерживается)

### Адаптивность:
- Видео адаптируется под размер экрана (mobile-first)
- Aspect ratio 16:9 сохраняется на всех устройствах
- В модальном окне высота видео: 400-500px в зависимости от ширины экрана

### Безопасность:
- Используется `escapeHtml` для всех пользовательских данных
- iframe имеет ограниченные разрешения: `allow="autoplay; encrypted-media; fullscreen; picture-in-picture; screen-wake-lock;"`

### Производительность:
- Autoplay отключен в модальном окне (пользователь сам нажимает Play)
- Lazy loading для превью изображений

## Проблемы и решения:

### Проблема: Видео VK не воспроизводится

**Причина:** Неправильная приватность видео в VK

**Решение:** 
1. Открыть настройки видео в VK
2. Установить приватность: "Все пользователи" или "По ссылке"
3. Проверить в режиме инкогнито браузера

### Проблема: Видео не отображается в iframe

**Причина:** Неверный формат ссылки

**Решение:**
- Использовать прямую ссылку: `https://vk.com/video-227283438_456239037`
- НЕ использовать короткие ссылки или ссылки на стены групп

### Проблема: Autoplay не работает

**Ответ:** Это нормально и ожидаемо
- Autoplay намеренно отключен в модальном окне
- Браузеры блокируют autoplay по умолчанию (политика безопасности)
- Пользователь сам нажимает кнопку Play

### Проблема: При закрытии модального окна видео продолжает играть

**Решение:** ✅ Исправлено!
- При закрытии модального окна содержимое очищается после завершения анимации (400мс)
- Удаление iframe из DOM автоматически останавливает воспроизведение видео
- Это происходит прозрачно для пользователя без прерывания анимации закрытия
