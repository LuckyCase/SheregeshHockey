# Дизайн модального окна новостей

## Обновлённый дизайн (баннерный формат)

### Структура модального окна

```
┌─────────────────────────────────────────┐
│  ╔═════════════════════════════════╗   │ ← Баннер новости
│  ║                                 ║   │   (400-500px высота)
│  ║     Первое фото (Hero Banner)   ║   │   - Во всю ширину
│  ║         object-fit: cover       ║   │   - Градиент снизу
│  ║                                 ║   │
│  ╚═════════════════════════════════╝   │
│         ▲                               │
│         │ Контент перекрывает на 60px  │
│    ┌────┴──────────────────────────┐   │
│    │  [X] Закрыть                  │   │
│    │                               │   │
│    │  [Закреплено] (если pinned)   │   │
│    │  12 февраля 2026              │   │

│    │  █ Заголовок новости          │   │ ← Зелёная полоска
│    │                               │   │
│    │  Полный текст новости...      │   │
│    │  (white-space: pre-wrap)      │   │
│    │                               │   │
│    │  ─────────────────────        │   │
│    │                               │   │
│    │  ╔═══════════════════╗        │   │ ← Доп. фото

│    │  ╔═══════════════════╗        │   │

```

## Ключевые улучшения

### 1. Hero Banner (главное фото)
- **Размер**: 400px (мобильный) → 450px (планшет) → 500px (десктоп)
- **Отображение**: `object-fit: cover` — фото заполняет всю область
- **Градиент**: Плавный переход снизу к фону (150px)
- **Эффект**: Создаёт впечатление полноценного баннера новости

### 2. Перекрывающий контент
- Контент "наезжает" на баннер сверху на **60px** (мобильный: 40px)
- Создаёт современный card-эффект
- Улучшает визуальную связь баннера и контента

### 3. Дополнительные изображения
- **Формат**: Полноширинные баннеры (не сетка)
- **Размер**: 300px (мобильный) → 350px (десктоп)
- **Расположение**: Вертикально друг под другом
- **Стиль**: Рамка + тень, hover-эффект (поднятие + зелёная рамка)

### 4. Анимация открытия
```css
transform: scale(0.8) translateY(30px);  /* Начальное состояние */
opacity: 0;

→

transform: scale(1) translateY(0);       /* Конечное состояние */
opacity: 1;
```
- **Эффект**: Окно "вырастает" и поднимается
- **Тайминг**: `cubic-bezier(0.34, 1.56, 0.64, 1)` — лёгкий "отскок"
- **Длительность**: 0.4s

## Технические детали

### CSS классы

```css
.news-modal__banner {
  height: 400px;              /* Базовая высота */
  position: relative;
  overflow: hidden;
}

.news-modal__banner::after {
  /* Градиент снизу */
  background: linear-gradient(to bottom, transparent, var(--color-bg));
  height: 150px;
}

.news-modal__body {
  margin-top: -60px;          /* Перекрытие баннера */
  z-index: 1;
}

.news-modal__image-item {
  height: 300px;              /* Доп. фото */
  border-radius: 8px;
  border: 2px solid;
}
```

### JavaScript изменения

```javascript
// Было:
var img = '<img class="news-modal__image" src="...">';

// Стало:
var banner = '<div class="news-modal__banner">' +
  '<img class="news-modal__image" src="...">' +
  '</div>';
```

## Визуальные эффекты

### Кнопка закрытия
- **Дефолт**: Зелёная рамка, прозрачный фон
- **Hover**: Зелёный фон, белый цвет, поворот на 90°
- **Active**: Поворот + масштаб 0.95

### Дополнительные фото
- **Дефолт**: Серая рамка, лёгкая тень
- **Hover**:
  - Поднятие на 4px
  - Зелёная рамка
  - Увеличенная тень

### Прокрутка
- **Ширина**: 8px
- **Цвет**: Зелёный (брендовый)
- **Hover**: Светлее

## Адаптивность

### Мобильные (< 768px)
- Баннер: 400px
- Перекрытие: 40px
- Доп. фото: 300px
- Отступы: уменьшены

### Планшеты (768px - 1024px)
- Баннер: 450px
- Перекрытие: 60px
- Доп. фото: 300px

### Десктоп (> 1024px)
- Баннер: 500px
- Перекрытие: 60px
- Доп. фото: 350px

## Примеры использования

### Новость с одним фото
```json
{
  "images": ["photo.jpg"]
}
```
→ Только hero banner, без дополнительных фото

### Новость с тремя фото
```json
{
  "images": ["photo1.jpg", "photo2.jpg", "photo3.jpg"]
}
```
→ Hero banner (photo1) + 2 полноширинных баннера (photo2, photo3)

### Новость без фото
```json
{
  "images": []
}
```
→ Нет баннера, контент начинается сразу

## Рекомендации по фото

### Hero Banner (первое фото)
- **Формат**: Горизонтальный (landscape)
- **Соотношение**: 16:9 или 21:9
- **Разрешение**: Минимум 1200px по ширине
- **Композиция**: Важный контент по центру

### Дополнительные фото
- **Формат**: Горизонтальный предпочтительнее
- **Разрешение**: Минимум 900px по ширине
- **Количество**: Без ограничений (но 2-4 оптимально)
