# Хоккей Шерегеша

Статический двуязычный сайт (RU / EN) об истории хоккея с шайбой в посёлке Шерегеш: десятилетия (1970–2000), команды, воспоминания, фотоальбом, площадки.

## Как вносить изменения

| Что изменить | Где редактировать |
|---|---|
| Структура / разметка страницы | `src/template.html` |
| Русские тексты | `src/i18n/ru.json` |
| Английские тексты | `src/i18n/en.json` |
| Новости команды (раздел "Наши дни") | 🎛️ **Админ-панель** `/manage-content-2026/` или `assets/js/data/today-data.json` |

После любых правок запустить сборку:

```bash
npm run build
```

Скрипт перегенерирует оба файла: `index.html` (RU) и `en/index.html` (EN).

## Добавление видео в новости

### Через админ-панель (рекомендуется):

1. Откройте админ-панель: `/manage-content-2026/index.html`
2. Авторизуйтесь с GitHub токеном
3. Перейдите на вкладку "Today" → "Новости"
4. В поле "🎥 Видео из VK.com" вставьте прямую ссылку:
   ```
   https://vk.com/video-227283438_456239037
   ```
5. Загрузите превью-фото (опционально)
6. Нажмите "Опубликовать"

### Вручную (через JSON):

В новости можно встраивать видео из VK.com. Подробная инструкция находится в файле **[VIDEOS.md](docs/VIDEOS.md)**.

#### Быстрый старт:

1. Получите прямую ссылку на видео VK (например, `https://vk.com/video-227283438_456239037`)
2. Добавьте поле `videoUrl` в новость в файле `assets/js/data/today-data.json`:

```json
{
  "id": "news-example",
  "date": "2026-02-16",
  "titleRu": "Видео: Лучшие моменты",
  "titleEn": "Video: Best Moments",
  "contentRu": "Описание новости...",
  "contentEn": "News description...",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": ["assets/images/today/news/thumbnail.jpg"],
  "pinned": false
}
```

3. Видео будет автоматически встроено в карточку новости и модальное окно
