## Тест 6: Ошибки

### Неверный Client ID
- [ ] В консоли браузера (F12) появляется ошибка "Imgur upload failed"
- [ ] Сообщение "Failed to upload photos. Please try again."
- [ ] Кнопка "Отправить" снова активна

### Большой файл (>20 MB)
- [ ] Попытка загрузить файл >20 MB
- [ ] Imgur отклоняет загрузку
- [ ] Появляется сообщение об ошибке

### Неподдерживаемый формат
- [ ] Попытка загрузить .pdf или .doc
- [ ] Файл не выбирается (атрибут `accept` блокирует)

## Проверка на разных устройствах

- [ ] **Desktop**: Chrome/Firefox/Safari/Edge
- [ ] **Mobile**: Safari (iOS) / Chrome (Android)
- [ ] Превью фото отображается корректно
- [ ] Кнопка удаления "×" кликабельна на мобильном

## Известные ограничения

✅ Лимит Imgur: 1,250 загрузок/день (достаточно для некоммерческого сайта)  
✅ Размер файла: до 20 MB  
✅ Форматы: PNG, JPEG, JPG, GIF  

---

## Если что-то не работает

1. **Проверьте консоль браузера** (F12 → Console) — там будут ошибки
2. **Убедитесь, что Client ID добавлен** в `contact-form.js`
3. **Проверьте интернет-соединение** — загрузка идёт напрямую на Imgur
4. **Попробуйте другое фото** — возможно, файл повреждён
