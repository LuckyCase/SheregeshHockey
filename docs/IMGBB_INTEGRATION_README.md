# Обновление формы обратной связи — Загрузка фото через ImgBB

⚠️ **Важное изменение**: Imgur API больше не принимает новые регистрации с 2025 года. Мы используем **ImgBB** — бесплатную альтернативу с лучшими лимитами!

## Что сделано

✅ Добавлено поле для загрузки фотографий в форму обратной связи  
✅ Интеграция с **ImgBB API** (бесплатно, **БЕЗ ЛИМИТОВ** на запросы)  
✅ Превью выбранных фото перед отправкой  
✅ Возможность удалить фото из списка  
✅ Поддержка множественной загрузки (несколько фото)  
✅ Индикация процесса загрузки  
✅ Формат: PNG, JPEG, JPG, GIF, BMP, TIFF, WebP (до **32 MB** каждый!)  

## Как это работает

1. Пользователь выбирает фотографии через форму
2. Видит превью выбранных фото
3. При отправке формы:
   - Фото загружаются на **ImgBB** (бесплатное хранилище)
   - Получаются прямые ссылки на фото
   - Ссылки отправляются в **Formspree** в поле `photo_urls`
4. Вы получаете письмо с сообщением и ссылками на фото

## Что нужно сделать для работы

### 1. Получить ImgBB API Key (2 минуты!)

Подробная инструкция в файле **IMGBB_SETUP.md**

**Быстрый старт:**
1. Зарегистрируйтесь на https://imgbb.com/signup
2. Перейдите на https://api.imgbb.com/
3. Нажмите **"Get API Key"**
4. Скопируйте ваш API Key

### 2. Добавить API Key в код

Откройте файл `assets/js/modules/contact-form.js` (строка 5):

```javascript
var IMGBB_API_KEY = 'YOUR_IMGBB_API_KEY'; // ← Замените на ваш API Key
```

Замените `YOUR_IMGBB_API_KEY` на полученный ключ.

### 3. Протестировать

1. Откройте сайт в браузере
2. Нажмите "Написать нам"
3. Выберите фото (можно несколько)
4. Отправьте форму
5. Проверьте письмо на Formspree

```
https://i.ibb.co/abc123/photo1.jpg
https://i.ibb.co/def456/photo2.jpg
https://i.ibb.co/ghi789/photo3.jpg
```

## Преимущества ImgBB

✅ **Полностью бесплатно** (и ImgBB, и Formspree)  
✅ **БЕЗ ЛИМИТОВ на API-запросы** (у Imgur было 1250/день)  
✅ **До 32 MB на файл** (у Imgur было 20 MB)  
✅ **Принимает новые регистрации** (Imgur закрылся)  
✅ **Быстрая регистрация** — 2 минуты  
✅ **Прямые ссылки** — фото сразу открываются в браузере  
✅ **Множественная загрузка** — можно отправить много фото за раз  
✅ **Превью перед отправкой** — пользователь видит, что отправляет  

## Почему не Imgur?

🚫 **Imgur API закрыт для новых регистраций** с 2025 года  
🚫 Страница https://api.imgur.com/oauth2/addclient больше не работает  
🚫 Существующие приложения работают, но новые создать нельзя  

ImgBB — идеальная замена с лучшими условиями!

## Альтернативы (если нужно)

### Cloudinary (профессиональное решение)
- Бесплатно: 25 GB хранилища, 25 GB трафика/месяц
- Регистрация на https://cloudinary.com/
- Более сложная настройка, но больше возможностей

### GitHub Issues (совсем без внешних сервисов)
- Полностью бесплатно
- До 25 MB на файл
- Все сообщения в вашем репозитории
- Требует GitHub Personal Access Token

## Поддержка

Если что-то не работает:
1. Проверьте консоль браузера (F12 → Console) на ошибки
2. Убедитесь, что API Key добавлен в `contact-form.js`
3. Проверьте, что файлы соответствуют форматам PNG/JPG/GIF
4. Убедитесь, что размер файла не превышает 32 MB
