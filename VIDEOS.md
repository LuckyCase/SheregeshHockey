# Добавление видео в новости

В новости можно добавлять видео из VK.com. Видео отображается в карточке новости и в модальном окне при открытии.

---

## Поддерживаемые форматы ссылок VK

### 1. Прямая ссылка на видео

```
https://vk.com/video-227283438_456239037
```

Где:
- `-227283438` — ID владельца видео (группа/сообщество, начинается с минуса)
- `456239037` — ID самого видео

### 2. Код для вставки (iframe)

Вы можете получить код для вставки на странице видео VK, но **достаточно использовать прямую ссылку** — система автоматически преобразует её в нужный формат.

Пример кода для вставки:
```html
<iframe src="https://vk.com/video_ext.php?oid=-227283438&id=456239037&autoplay=1" 
        width="853" height="480" 
        allow="autoplay; encrypted-media; fullscreen; picture-in-picture; screen-wake-lock;" 
        frameborder="0" allowfullscreen>
</iframe>
```

## Добавление видео в новость

### Структура новости с видео в `today-data.json`

```json
{
  "id": "news-example-video",
  "date": "2026-02-15",
  "titleRu": "Видео: Лучшие моменты матча",
  "titleEn": "Video: Best Moments of the Match",
  "contentRu": "Смотрите видео с лучшими моментами матча...",
  "contentEn": "Watch the video with the best moments...",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": [
    "assets/images/today/news/thumbnail.jpeg"
  ],
  "pinned": false
}
```

### Поля:

- **`videoUrl`** (необязательное) — прямая ссылка на видео VK в формате `https://vk.com/video{oid}_{id}`
- **`images`** (необязательное) — массив изображений:
  - Если указан `videoUrl`, первое изображение используется как превью в карточке новости (с иконкой воспроизведения)
  - Если `videoUrl` не указан, первое изображение отображается как обычное фото
  - Остальные изображения показываются внизу модального окна

---

## Приоритеты отображения

### В карточке новости:

1. Если есть `videoUrl` **и** есть `images[0]` → показывается превью с иконкой ▶️
2. Если есть `videoUrl`, но нет изображений → показывается иконка видеокамеры 🎥
3. Если нет `videoUrl`, но есть `images[0]` → показывается обычное изображение

### В модальном окне:

1. Если есть `videoUrl` → видео отображается вверху (вместо баннера)
2. Если нет `videoUrl`, но есть `images[0]` → первое изображение показывается как баннер
3. Остальные изображения из массива `images` отображаются внизу после текста контента

## Настройки приватности VK

**Важно:** Убедитесь, что видео на VK доступно для просмотра без авторизации.

### Проверка:

1. Откройте ссылку на видео в режиме инкогнито браузера
2. Если видео воспроизводится — всё в порядке
3. Если требуется авторизация — измените настройки приватности видео в VK:
   - **«Все пользователи»** или **«По ссылке»** — подходит ✅
   - **«Только друзья»** или **«Только я»** — не подходит ❌

## Примеры

### Новость только с видео (без изображений):

```json
{
  "id": "news-video-only",
  "date": "2026-02-16",
  "titleRu": "Тренировка команды",
  "titleEn": "Team Training",
  "contentRu": "Видео с тренировки команды перед важным матчем.",
  "contentEn": "Training video before an important match.",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": [],
  "pinned": false
}
```

### Новость с видео и несколькими фото:

```json
{
  "id": "news-video-and-photos",
  "date": "2026-02-16",
  "titleRu": "Репортаж с матча",
  "titleEn": "Match Report",
  "contentRu": "Видео и фотографии с последнего матча против Новокузнецка.",
  "contentEn": "Video and photos from the last match against Novokuznetsk.",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": [
    "assets/images/today/news/match-preview.jpg",
    "assets/images/today/news/goal-moment.jpg",
    "assets/images/today/news/celebration.jpg"
  ],
  "pinned": true
}
```

В этом случае:
- Карточка: `match-preview.jpg` с иконкой воспроизведения
- Модальное окно:
  - Вверху: видео
  - Внизу: `match-preview.jpg`, `goal-moment.jpg`, `celebration.jpg`

## Технические детали

### Как работает:

1. JavaScript-модуль `today.js` анализирует поле `videoUrl`
2. Извлекает `oid` и `id` из ссылки VK
3. Генерирует embed-код с использованием `https://vk.com/video_ext.php`
4. Встраивает адаптивный iframe (responsive, 16:9)

### Автоматические параметры:

- **В модальном окне:** autoplay отключен (`autoplay=0`) — пользователь сам нажимает Play
- **Разрешения iframe:** `allow="autoplay; encrypted-media; fullscreen; picture-in-picture; screen-wake-lock;"`
- **Адаптивность:** видео подстраивается под ширину экрана (mobile-first)
- **Остановка воспроизведения:** При закрытии модального окна iframe автоматически удаляется из DOM, что останавливает воспроизведение видео

---

## Удаление видео из новости

Чтобы убрать видео, просто удалите поле `videoUrl` или установите его в `null`:

```json
{
  "videoUrl": null
}
```

или

```json
{
  // просто не указывайте поле videoUrl
}
```

## Поддержка других платформ

Сейчас поддерживается только VK.com. 

Для добавления поддержки YouTube, Rutube и других платформ необходимо расширить функции `parseVkVideoUrl` и `getVkVideoEmbedUrl` в файле `assets/js/modules/today.js`.
