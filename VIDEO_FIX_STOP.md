# Исправление: Остановка видео при закрытии модального окна

**Дата:** 16 февраля 2026  
**Версия:** 1.1.1

---

## Проблема

При закрытии модального окна с видео из VK.com, звук продолжал воспроизводиться в фоновом режиме, несмотря на то что окно было закрыто.

### Причина:

Iframe с видео оставался в DOM дереве после закрытия модального окна. Хотя элемент был скрыт (`hidden` атрибут), браузер продолжал загружать и воспроизводить видео в iframe.

---

## Решение

Обновлена функция `closeNewsModal()` в файле `assets/js/modules/today.js`:

### До:

```javascript
function closeNewsModal() {
  var modal = document.getElementById('news-modal');
  if (!modal) return;

  if (document.activeElement && modal.contains(document.activeElement)) {
    document.activeElement.blur();
  }

  modal.setAttribute('aria-hidden', 'true');
  modal.setAttribute('hidden', '');
  document.body.style.overflow = '';
}
```

### После:

```javascript
function closeNewsModal() {
  var modal = document.getElementById('news-modal');
  var body = document.getElementById('news-modal-body');
  if (!modal) return;

  if (document.activeElement && modal.contains(document.activeElement)) {
    document.activeElement.blur();
  }

  modal.setAttribute('aria-hidden', 'true');
  modal.setAttribute('hidden', '');
  document.body.style.overflow = '';

  // Очищаем содержимое модального окна после завершения анимации
  // Это удаляет iframe из DOM и останавливает видео
  setTimeout(function() {
    if (body && modal.getAttribute('aria-hidden') === 'true') {
      body.innerHTML = '';
    }
  }, 400);
}
```

---

## Как работает:

1. **Закрытие модального окна:**
   - Устанавливается атрибут `aria-hidden="true"`
   - Добавляется атрибут `hidden`
   - Запускается CSS анимация закрытия (transition: 0.4s)

2. **Задержка 400мс:**
   - Соответствует длительности CSS transition
   - Позволяет анимации завершиться плавно

3. **Очистка контента:**
   - После завершения анимации вызывается `body.innerHTML = ''`
   - Все элементы внутри модального окна удаляются из DOM
   - Удаление iframe автоматически останавливает воспроизведение видео

4. **Проверка состояния:**
   - Перед очисткой проверяется `aria-hidden === 'true'`
   - Это предотвращает очистку, если окно было открыто повторно до истечения таймера

---

## Преимущества решения:

✅ **Полная остановка видео:** iframe удаляется из DOM, браузер гарантированно останавливает воспроизведение

✅ **Плавная анимация:** контент очищается после завершения анимации, пользователь не видит мерцания

✅ **Экономия ресурсов:** после закрытия окна видео не использует сеть и процессор

✅ **Безопасность:** проверка состояния модального окна предотвращает race conditions

✅ **Совместимость:** работает во всех современных браузерах

## Техническая информация:

### Задержка 400мс:

Соответствует длительности CSS transition в `_today.css`:

```css
.news-modal__content {
  transition: all 0.4s cubic-bezier(0.34, 1.56, 0.64, 1);
}
```

### Альтернативные решения (не используются):

1. **postMessage API:** Отправка команды `pauseVideo` в iframe
   - ❌ Не поддерживается VK video embed API

2. **Замена src на пустой:** `iframe.src = ''`
   - ❌ Может вызвать ошибки в консоли

3. **display: none:** Скрытие iframe
   - ❌ Видео продолжает воспроизводиться в фоне

4. **Удаление из DOM:** `body.innerHTML = ''`
   - ✅ **Выбранное решение:** простое, надёжное, эффективное
