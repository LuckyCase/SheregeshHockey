# Добавление видео в новости

В новости можно добавлять видео с любых популярных видеохостингов. Видео отображается в карточке новости и в модальном окне при открытии.

---

## Поддерживаемые платформы

| Платформа | Пример ссылки |
|-----------|---------------|
| **VK** | `https://vk.com/video-227283438_456239037` |
| **VK Video** | `https://vkvideo.ru/video-227283438_456239073` |
| **YouTube** | `https://www.youtube.com/watch?v=dQw4w9WgXcQ` |
| **YouTube (короткая)** | `https://youtu.be/dQw4w9WgXcQ` |
| **YouTube Shorts** | `https://www.youtube.com/shorts/dQw4w9WgXcQ` |
| **Rutube** | `https://rutube.ru/video/abc123def456/` |
| **Dzen** | `https://dzen.ru/video/watch/abc123def456` |
| **OK.ru** | `https://ok.ru/video/1234567890` |
| **Прямой embed-URL** | Любой `https://...` URL с iframe/embed/player |

Система автоматически определяет платформу и генерирует правильный embed-код.

## Добавление видео в новость

### Через админ-панель

1. Откройте админ-панель (`manage-content-2026/index.html`)
2. Создайте или отредактируйте новость
3. Вставьте ссылку на видео в поле **«Видео»**
4. Сохраните

### Вручную в `today-data.json`

```json
{
  "id": "news-example-video",
  "date": "2026-02-15",
  "titleRu": "Видео: Лучшие моменты матча",
  "titleEn": "Video: Best Moments of the Match",
  "contentRu": "Смотрите видео с лучшими моментами матча...",
  "contentEn": "Watch the video with the best moments...",
  "videoUrl": "https://vk.com/video-227283438_456239037",
  "images": [
    "assets/images/today/news/thumbnail.jpeg"
  ],
  "pinned": false
}
```

### Поля:

- **`videoUrl`** (необязательное) — ссылка на видео с любой поддерживаемой платформы
- **`images`** (необязательное) — массив изображений:
  - Если указан `videoUrl`, первое изображение используется как превью в карточке новости (с иконкой воспроизведения)
  - Если `videoUrl` не указан, первое изображение отображается как обычное фото
  - Остальные изображения показываются внизу модального окна

---

## Приоритеты отображения

### В карточке новости:

1. Если есть `videoUrl` **и** есть `images[0]` → показывается превью с иконкой ▶️
2. Если есть `videoUrl`, но нет изображений → показывается иконка видеокамеры 🎥
3. Если нет `videoUrl`, но есть `images[0]` → показывается обычное изображение

### В модальном окне:

1. Если есть `videoUrl` → видео отображается после текста (iframe)
2. Если нет `videoUrl`, но есть `images[0]` → первое изображение показывается как баннер
3. Остальные изображения из массива `images` отображаются внизу после текста контента

## Настройки приватности

**Важно:** Убедитесь, что видео доступно для просмотра без авторизации.

### Проверка:

1. Откройте ссылку на видео в режиме инкогнито браузера
2. Если видео воспроизводится — всё в порядке
3. Если требуется авторизация — измените настройки приватности на платформе

### Рекомендации по платформам:

- **VK**: настройка «Все пользователи» или «По ссылке»
- **YouTube**: настройка «Доступ по ссылке» (Unlisted) или «Открытый доступ» (Public)
- **Rutube**: доступ «Для всех»
- **OK.ru**: видео должно быть публичным

## Технические детали

### Как работает:

1. JavaScript-модуль `today.js` анализирует поле `videoUrl`
2. Автоматически определяет платформу по паттерну URL
3. Генерирует правильный embed-URL для конкретной платформы
4. Встраивает адаптивный iframe (responsive, 16:9)

### Преобразование URL по платформам:

| Платформа | Входной URL | Embed URL |
|-----------|-------------|-----------|
| VK | `vk.com/video-ID_ID` | `vk.com/video_ext.php?oid=ID&id=ID` |
| VK Video | `vkvideo.ru/video-ID_ID` | `vk.com/video_ext.php?oid=ID&id=ID` |
| YouTube | `youtube.com/watch?v=ID` | `youtube.com/embed/ID?rel=0` |
| Rutube | `rutube.ru/video/ID/` | `rutube.ru/play/embed/ID` |
| Dzen | `dzen.ru/video/watch/ID` | `dzen.ru/embed/ID` |
| OK.ru | `ok.ru/video/ID` | `ok.ru/videoembed/ID` |

### Автоматические параметры:

- **В модальном окне:** autoplay отключен — пользователь сам нажимает Play
- **Разрешения iframe:** `allow="autoplay; encrypted-media; fullscreen; picture-in-picture; screen-wake-lock;"`
- **Адаптивность:** видео подстраивается под ширину экрана (mobile-first)
- **Остановка воспроизведения:** При закрытии модального окна iframe автоматически удаляется из DOM, что останавливает воспроизведение видео

## Удаление видео из новости

Чтобы убрать видео, просто удалите поле `videoUrl` или установите его в пустую строку:

```json
{
  "videoUrl": ""
}
```

Или не указывайте поле `videoUrl` вообще.
