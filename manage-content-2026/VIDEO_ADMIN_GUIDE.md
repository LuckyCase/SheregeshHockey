# Добавление видео через админ-панель

## Доступ к админке

Админ-панель находится по адресу: `/manage-content-2026/index.html`

Для локального доступа:
```
http://localhost:8000/manage-content-2026/index.html
```

Для продакшн:
```
https://ваш-сайт.com/manage-content-2026/index.html
```

---

## Авторизация

### Шаг 1: Пароль (опционально)

По умолчанию пароль не установлен — просто нажмите "Войти" с пустым полем.

Для настройки пароля см. `PASSWORD-SETUP.md`.

### Шаг 2: GitHub Token

Вам нужен **GitHub Personal Access Token** с правами `repo` (Contents: Read and write).

**Как создать токен:**

1. Откройте https://github.com/settings/tokens
2. Нажмите "Generate new token" → "Generate new token (classic)"
3. Название: `Sheregesh Hockey Admin`
4. Выберите права: `repo` (полный доступ к репозиториям)
5. Срок действия: `No expiration` или на ваше усмотрение
6. Нажмите "Generate token"
7. **Скопируйте токен** (ghp_xxxxxxxxxxxx...)

**Вставьте токен в админку:**

- GitHub Token: `ghp_ваш_токен`
- Owner: `luckycase` (или ваш GitHub username)
- Repository: `SheregeshHockey`
- Branch: `master`

Нажмите "Подключиться".

## Добавление новости с видео

### 1. Откройте вкладку "Новости"

Админка открывается на вкладке "Today" → "Новости" по умолчанию.

### 2. Заполните поля:

#### Обязательные поля:

- **Заголовок (RU):** `Видео: Лучшие моменты матча`
- **Title (EN):** `Video: Best Moments of the Match`
- **Дата:** Выберите дату новости

#### Опциональные поля:

- **Текст (RU):** Описание новости
- **Text (EN):** Description in English
- **Закрепить:** Галочка для закрепления новости вверху списка

#### 🎥 Добавление видео:

В поле **"Видео из VK.com (опционально)"** вставьте прямую ссылку на видео:

```
https://vk.com/video-227283438_456239037
```

**Где взять ссылку:**

1. Откройте видео на VK.com
2. Скопируйте URL из адресной строки браузера
3. Формат: `https://vk.com/video{oid}_{id}`

#### Добавление фото:

- Если добавлено видео, **первое фото** используется как **превью** (thumbnail) в карточке новости
- Остальные фото отображаются **под видео** в модальном окне

**Загрузка фото:**
- Перетащите файлы в область "Перетащите файлы сюда"
- Или нажмите на область и выберите файлы

### 3. Предпросмотр (опционально)

Нажмите кнопку **"Предпросмотр"** чтобы увидеть, как будет выглядеть новость.

### 4. Публикация

Нажмите кнопку **"Опубликовать"**.

Админка:
1. Загрузит фото на GitHub (если есть)
2. Сохранит данные в `today-data.json`
3. Создаст commit в репозитории
4. Покажет сообщение "Новость опубликована!"

## Редактирование новости с видео

1. В списке "Существующие новости" найдите нужную новость
2. Нажмите кнопку **"Ред."** (Редактировать)
3. Форма заполнится данными новости
4. Измените нужные поля (в том числе `videoUrl`)
5. Нажмите **"Сохранить"**

---

## Удаление новости

1. В списке новостей нажмите **"Удалить"**
2. Подтвердите удаление

⚠️ **Внимание:** Удаление необратимо!

## Особенности работы с видео

### Поддерживаемые ссылки VK:

✅ Прямая ссылка на видео:
```
https://vk.com/video-227283438_456239037
```

❌ Короткие ссылки или ссылки на посты НЕ поддерживаются:
```
https://vk.cc/abcdef
https://vk.com/wall-227283438_123
```

### Приоритет отображения:

**В карточке новости:**
- Если есть видео + фото → показывается превью с иконкой ▶️
- Если есть только видео → иконка видеокамеры 🎥
- Если есть только фото → обычное изображение

**В модальном окне:**
- Видео отображается вверху (баннер)
- Все фото показываются внизу после текста

### Проверка доступности видео:

Убедитесь, что видео на VK **доступно без авторизации**:

1. Откройте ссылку в режиме инкогнито
2. Если видео воспроизводится — ✅ всё в порядке
3. Если требует авторизации — измените настройки приватности в VK

**Заголовок (RU):**

## Частые проблемы

### Видео не отображается на сайте

**Причина:** Неправильная ссылка или приватность видео

**Решение:**
1. Проверьте формат ссылки: `https://vk.com/video{oid}_{id}`
2. Проверьте настройки приватности видео в VK
3. Убедитесь, что видео доступно без авторизации

### Фото не загрузилось

**Причина:** Слишком большой размер файла или сетевая ошибка

**Решение:**
1. Уменьшите размер фото (рекомендуется до 2-3 МБ)
2. Попробуйте загрузить снова
3. Проверьте соединение с интернетом

### Ошибка "Не удалось сохранить"

**Причина:** Проблема с GitHub токеном или правами

**Решение:**
1. Проверьте, что токен действителен
2. Убедитесь, что у токена есть права `repo`
3. Проверьте Owner/Repository/Branch

- ✅ Админка защищена паролем (опционально)
- ✅ Доступ только у администратора с GitHub токеном

**Рекомендации:**
- Не передавайте токен третьим лицам
- Регулярно обновляйте токен
- Используйте токен только с необходимыми правами
